# GIS_Axioma_CAD_to_GIS_converter
Импорт САПР в ГИС (DWG/DXF)


Плагин для Аксиомы. Конвертирует чертежи DWG и DXF в форматы ГИС: 
TAB (MapInfo), SHP (Shapefile), MIF/MID (MapInfo Interchange).


Основные возможности:  
	    - Наличие пакетного импорта файлов
	    - Разбивка по слоям чертежа или слияние в единый файл
	    - Выбор системы координат для выходных файлов: план-схема или реальная СК
	    - Автоподбор рамки карты по размеру чертежа или по рекомендуемым значениям
	    - Контроль точности шага привязки при выборе значений рамки карты
	    - Предупреждение о перезаписи существующих файлов
	    - Открытие результатов в Аксиоме (кроме MIF/MID) 


Установка производится путем добавления *.axp-файла в раздел "дополнительные модули".
